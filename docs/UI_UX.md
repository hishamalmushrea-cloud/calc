# خطة الواجهات

## الرئيسية
هدف: قرار في 3 ثوانٍ.
بطاقات قابلة للنقر: الصندوق، مبيعات الفترة، مصروف، صافي تقديري، لك، عليك.
شريط فترة: اليوم / أمس / أسبوع / شهر / سنة / مخصص.
Empty: «ابدأ بإضافة محل ثم عملية».

## إضافة عملية
خطوات: نوع (شرائح) → طرف تلقائي إن لزم → مبلغ → حفظ.
المزيد: تاريخ، سند، طريقة دفع، حساب نقدي، ملاحظات.

## العميل
لوحة رصيد، نسبة تحصيل، قائمة عمليات، مشاركة كشف، إغلاق حساب.

## الأخطاء
رسائل عربية: «أدخل مبلغًا أكبر من صفر»، «رقم السند مستخدم»، «التاريخ خارج السنة المالية».
