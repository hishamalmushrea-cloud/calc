# خطة الواجهات

## الرئيسية
هدف: قرار في 3 ثوانٍ.
بطاقات: صافي النقد، لك عند العملاء، عليك للموردين، سلف العملاء، أرصدة الموردين لصالحك.
Empty: «ابدأ بإضافة محل ثم عملية».
شرح قصير يفصل الأرصدة عن الربح.

## المزيد (بعد المرحلة الرابعة)
ترتيب: المحلات → الموظفون → إغلاق اليوم → الأمان → التصنيفات → Google → نسخ محلي → سحابة اختيارية → فحص البيانات → استيراد → التدقيق.

## البيع الآجل والتحصيل
الآجل يظهر العميل وتاريخ الاستحقاق فورًا.
التحصيل يطلب «العميل الذي يسدّد الآن».

## الاستعادة السحابية
تأكيد صريح قبل اختيار الملف أو WebDAV.
استعادة Google مع بيانات محلية تتطلب كتابة كلمة «استعادة».

## الأخطاء
رسائل عربية لغير المحاسب: مبلغ أكبر من صفر، تعذر الاستعادة مع خطوة تالية واضحة.
