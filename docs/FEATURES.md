# نطاق الإصدار الأول (v1)

## أساسي (مُنفَّذ)
- محلات متعددة + أرشفة
- عملاء وموردون + رصيد افتتاحي
- عمليات: بيع، شراء، مصروف، إيراد، تحصيل، سداد، تحويل
- دفتر أستاذ وكشف حساب
- لوحة رئيسية بفترات
- بحث وتصفية
- تقارير أساسية + مقارنة فترات
- أعمار ديون مبسطة
- نسخ احتياطي/استعادة JSON مع نسخة قبل الاستعادة
- قفل PIN اختياري
- عربي RTL، وضع داكن
- تصدير CSV لكشف الحساب
- مشاركة نصية عبر Share Sheet

## متقدم ظاهر في الإعدادات
- سنة مالية
- تصنيف عملاء كمؤشر
- تنبيهات محلية اختيارية
- إغلاق يوم
- إغلاق حساب طرف

## أُضيف لاحقًا في الواجهة
- PDF تقرير الفترة + مشاركة
- استيراد CSV بمعاينة ثم تنفيذ بمعاملة
- رسوم أعمدة بسيطة في الرئيسية والتقارير
- قفل PIN + بصمة اختيارية
- إغلاق يوم (نقد متوقع/فعلي/فرق)
- إغلاق حساب طرف (أرشفة + رصيد افتتاحي جديد)
- شاشة أعمار ديون
- نسخ احتياطي تلقائي يومي (WorkManager) مع الاحتفاظ بـ N نسخ

## أُضيف في تحسينات الاستخدام اليومي
- أزرار سريعة من الرئيسية: بيع / تحصيل / مصروف
- مقارنة مبيعات الفترة الحالية بالسابقة (فرق ونسبة)
- تنبيه بعدد الحسابات ذات ديون أقدم من 60 يومًا
- لوحة الحساب (عميل/مورد): الرصيد، المبيعات، التحصيل، نسبة التحصيل، آخر العمليات
- مشاركة كشف الحساب كنص عبر Share Sheet
- تصدير CSV كامل (عمليات + أسماء) ومشاركته
- قائمة النسخ الاحتياطية مع استعادة (مع نسخة حماية قبل الاستبدال)
- سجل التدقيق (Audit Log) ظاهر في «المزيد»
- قفل PIN بتجزئة SHA-256 مع ملح عشوائي (مع توافق الرموز القديمة)

## مؤجل
- مخزون كامل، فواتير بنود/ضريبة، Excel xlsx، مزامنة سحابية، تعدد مستخدمين حي، تشفير نسخة بكلمة مرور
