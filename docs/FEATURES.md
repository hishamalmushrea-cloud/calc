# ميزات دفتري — الإصدار 1.3

## دفتر البيع اليومي
- تبويب «بيع» مستقل يعيد استخدام نفس العمليات والقيود المحاسبية دون نسخ البيانات.
- دفتر أسبوعي مرتبط بالتاريخ، وتقويم شهري، وفتح أي يوم قديم.
- إدخال سريع للبيع والمخرج، وطرق دفع متعددة، وتصنيفات، وبيع آجل مرتبط بالعميل.
- ملخص يومي، ملاحظات، إغلاق صريح وإعادة فتح مسجلة، وتأكيد أرشفة وتراجع.
- بحث وفلاتر حسب الفترة والنوع والدفع والتصنيف والعميل والملاحظة والمبلغ.
- ملخص أسبوعي/شهري، متوسطات، أفضل وأضعف يوم، مقارنة الفترة السابقة، ورسوم
  للمبيعات وطرق الدفع وتصنيفات المخارج.
- تكرار يدوي بعد تأكيد، ومشاركة اليوم، وتصدير PDF وExcel وCSV.

## دفتر الحسابات (أشخاص له/عليه)
- دفتر أشخاص مستقل عن العملاء/الموردين: اسم، مبلغ، **له / عليه**، وصافٍ يُحسب تلقائيًا.
- سجل عمليات لكل شخص: التاريخ والوقت، نوع العملية (له / عليه / تسديد)، المبلغ، العملة،
  والتفاصيل، مع **رصيد جارٍ** لكل سطر وصفحة مستقلة لكل شخص.
- نافذة تسجيل بسيطة: اسم الشخص، **نوع العملية (له / عليه / تسديد)** قابل للتغيير، التاريخ،
  المبلغ، التفاصيل، اختيار العملة، ثم زر حفظ واحد يتلوّن بحسب النوع. وأزرار إضافة سريعة
  **+ له / + عليه / + تسديد** على بطاقة كل شخص في القائمة وفي صفحة الشخص.
- إغلاق نافذة عملية جديدة فيها بيانات مكتوبة يطلب تأكيدًا حتى لا تضيع بالخطأ.
- نظام عملات مرن: عملات رسمية أو من إنشاء المستخدم (اسم ورمز اختياري وعدد خانات)،
  ومنها عملة «محلي» بلا رمز، وعملة افتراضية قابلة للتغيير.
- الأرصدة تُحسب لكل عملة على حدة ومن العمليات مباشرة؛ لا يوجد رصيد مخزّن ينحرف.
- رصيد افتتاحي عند إنشاء الشخص يُسجَّل كعملية عادية تظهر في السجل.
- أرشفة ناعمة للأشخاص والعمليات والعملات مع بقاء السجل والأرصدة القديمة، ومشاركة كشف
  حساب نصي، وسجل تدقيق، وصلاحيات موظفين.
- **تراجع** عن حذف عملية من شريط الرسائل (`AccountsBookRepository.restoreEntry`) يعيد
  العملية ورصيدها كما كانت، لأنه حذف أرشيفي لا محو.

## الحسابات والعمليات
- محلات متعددة، وعملاء وموردون، وأرصدة افتتاحية وقيد مزدوج داخلي.
- بيع/شراء/مصروف/إيراد/تحصيل/سداد/تحويل، نقدي أو آجل.
- ترقيم سندات تلقائي مستقل لكل محل مع السماح بالتعديل ومنع التكرار.
- تاريخ استحقاق افتراضي بعد 30 يومًا للبيع الآجل مع إمكانية تعديله.
- تذكير يومي بالحسابات المستحقة عبر WorkManager وإشعارات Android.
- تصنيفات للمصروفات والإيرادات وتقرير تجميعي حسب التصنيف.
- أرشفة ناعمة مع تأكيد وزر تراجع، وسجل تدقيق.

## الحسابات والكشوف
- كشف حساب نصي برصيد جارٍ لكل سطر.
- PDF مستقل لسند العملية، إضافة إلى PDF/Excel لتقرير الفترة.
- بحث باسم الحساب أو رقم الهاتف، واتصال وWhatsApp من الواجهة.
- حسابات مقترحة للوصول السريع داخل نموذج العملية.
- أعمار ديون FIFO، ومتأخرون محسوبون من تاريخ الاستحقاق الفعلي.

## النسخ والاستعادة
- نسخة SQLite محلية بعد WAL checkpoint، ونسخة AES/GCM مشفرة بكلمة مرور.
- نسخ يومي تلقائي مع سياسة احتفاظ ونسخة أمان قبل كل استعادة.
- مجلد سحابي عبر Storage Access Framework (ومن ضمنه Google Drive).
- WebDAV اختياري مع بيانات اعتماد محفوظة في EncryptedSharedPreferences.
- استعادة من مزود الملفات أو أحدث WebDAV ثم إعادة تشغيل نظيفة تلقائيًا.

## الخصوصية والتخصيص
- PIN مجزأ بـ PBKDF2، وبصمة اختيارية، وقفل 30 ثانية بعد خمس محاولات فاشلة.
- وضع خصوصية لإخفاء الأرصدة.
- عملة المحل مستخدمة في كل تنسيقات المبالغ، مع أرقام لاتينية اختيارية.
- عربي وإنجليزي، RTL، ووضعان فاتح وداكن.

## الواجهة والوصول السريع
- واجهة Compose مقسمة إلى شاشات وحدث موحد `UiEvent`.
- شاشة «المزيد» مرتبة: محل، موظفون، أمان، نسخ Google، نسخ محلي، سحابة اختيارية، فحص بيانات.
- استعادة سحابية بتأكيد صريح؛ استعادة Google مع بيانات محلية تتطلب كتابة كلمة التأكيد.
- البيع الآجل والتحصيل يظهران العميل والاستحقاق فورًا دون إخفائهما في التفاصيل.
- لوحة رئيسية وتقارير تفصل «لك/عليك» عن الربح، مع حالة فارغة ورسائل لغير المحاسب.
- NavigationRail للشاشات العريضة/الأفقية وشريط سفلي للهواتف.
- **زر الرجوع يرجع خطوة لا يخرج من التطبيق**: يُغلق أولًا النافذة المفتوحة (عملية، شخص،
  عملة، فاتورة، تفاصيل موظف، مبدّل الموظف، نافذة بيع)، ثم صفحة الشخص، ثم الشاشة الثانوية
  (دفتر الحسابات/المخزون/النسخ السحابي/الموظفون)، ثم يعود إلى اللوحة الرئيسية، ولا يعمل
  أبدًا والشاشة مقفلة بالـ PIN. وفي الشاشة الرئيسية يتطلب الخروج ضغطة ثانية خلال ثانيتين
  مع تنبيه «اضغط زر الرجوع مرة أخرى للخروج».
- **شريط التنقّل يعمل من أي شاشة**: اختيار «العمليات» أو «بيع» أو أي تبويب وأنت داخل شاشة
  ثانوية يُغلقها وينقلك للتبويب فورًا (كان التبويب يتغير وتبقى الشاشة الثانوية ظاهرة).
- Widget يعرض صافي نقد اليوم (مع احترام الخصوصية) وزر بيع سريع.
- رسوم ومقارنات فترات، وتصدير/استيراد CSV.
