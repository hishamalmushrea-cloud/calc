# نطاق الإصدار الأول (v1)

## أساسي (مُنفَّذ)
- محلات متعددة + أرشفة
- عملاء وموردون + رصيد افتتاحي
- عمليات: بيع، شراء، مصروف، إيراد، تحصيل، سداد، تحويل
- دفتر أستاذ وكشف حساب
- لوحة رئيسية بفترات
- بحث وتصفية
- تقارير أساسية + مقارنة فترات
- أعمار ديون مبسطة
- نسخ احتياطي/استعادة JSON مع نسخة قبل الاستعادة
- قفل PIN اختياري
- عربي RTL، وضع داكن
- تصدير CSV لكشف الحساب
- مشاركة نصية عبر Share Sheet

## متقدم ظاهر في الإعدادات
- سنة مالية
- تصنيف عملاء كمؤشر
- تنبيهات محلية اختيارية
- إغلاق يوم
- إغلاق حساب طرف

## أُضيف لاحقًا في الواجهة
- PDF تقرير الفترة + مشاركة
- استيراد CSV بمعاينة ثم تنفيذ بمعاملة
- رسوم أعمدة بسيطة في الرئيسية والتقارير
- قفل PIN + بصمة اختيارية
- إغلاق يوم (نقد متوقع/فعلي/فرق)
- إغلاق حساب طرف (أرشفة + رصيد افتتاحي جديد)
- شاشة أعمار ديون
- نسخ احتياطي تلقائي يومي (WorkManager) مع الاحتفاظ بـ N نسخ

## أُضيف في تحسينات الاستخدام اليومي
- أزرار سريعة من الرئيسية: بيع / تحصيل / مصروف
- مقارنة مبيعات الفترة الحالية بالسابقة (فرق ونسبة)
- تنبيه بعدد الحسابات ذات ديون أقدم من 60 يومًا
- لوحة الحساب (عميل/مورد): الرصيد، المبيعات، التحصيل، نسبة التحصيل، آخر العمليات
- مشاركة كشف الحساب كنص عبر Share Sheet
- تصدير CSV كامل (عمليات + أسماء) ومشاركته
- قائمة النسخ الاحتياطية مع استعادة (مع نسخة حماية قبل الاستبدال)
- سجل التدقيق (Audit Log) ظاهر في «المزيد»
- قفل PIN بتجزئة PBKDF2 (مع توافق التنسيقات القديمة)

## جولة تقوية الأساس
- GitHub Actions CI: JDK 17 → اختبارات → assembleDebug → رفع APK (مع Gradle Wrapper)
- إزالة `fallbackToDestructiveMigration` + بنية مهاجرات Room آمنة (`Migrations.ALL`) + `exportSchema`
- تشفير النسخ الاحتياطية بكلمة مرور (AES/GCM + PBKDF2) مع استعادة مشفرة
- إنشاء حساب (عميل/مورد) inline من شاشة العملية
- اختيار تاريخ العملية (إدخال بأثر رجعي)
- تعديل العملية (مبلغ، تاريخ، ملاحظات، رقم سند، آجل/نقدي) مع إعادة بناء القيد
- أعمار ديون FIFO حقيقية على الفواتير غير المسددة
- PDF عربي RTL سليم عبر StaticLayout (تشكيل حروف صحيح)
- اختبارات وحدة: Money، PinHasher، CsvParser، AgingFifo (يشغّلها الـ CI)

## جولة ميزات السوق (منقولة من تحليل appcalc)
- تقرير «العملاء المتأخرون» بعدد أيام التأخير (من آخر بيع/تحصيل)
- حد ائتمان لكل حساب مع تنبيه عند بلوغه
- تصنيفات العملاء (حقل حر) تُعرض وتُعدَّل
- أول Migration Room حقيقية (v1 → v2) تُضيف عمود `creditLimitMinor` دون مسح البيانات
