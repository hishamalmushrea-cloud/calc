# تدقيق المشروع — دفتر الحسابات (دفتري)

تاريخ التدقيق: 2026-08-20

## ما الموجود قبل العمل
- مستودع شبه فارغ: `README.md` بعنوان `# calc` فقط.
- لا يوجد كود Android، ولا قاعدة بيانات، ولا اختبارات.

## القرار
بناء تطبيق Android أصلي من الصفر (ليس تطوير مشروع قائم)، مع الحفاظ على التوثيق والهيكل القابل للتوسع.

## ما الناقص (قبل التنفيذ)
كل شيء: Gradle، Compose، Room، الشاشات، المنطق المحاسبي، النسخ الاحتياطي، الاختبارات.

## المخاطر
- بيئة البناء الحالية قد لا تحتوي على JDK/Android SDK.
- نطاق المنتج ضخم؛ الإصدار الأول يجب أن يبقى مفيدًا دون مخزون/فواتير/ضرائب معقدة.

## خطة التنفيذ المختصرة
1. توثيق البحث والمنطق والمعمارية.
2. نموذج بيانات Room مع ترحيل الإصدارات.
3. طبقة نطاق محاسبي (مبالغ Long بوحدة صغرى).
4. واجهة Compose عربية RTL.
5. نسخ احتياطي JSON + استعادة آمنة.
6. اختبارات وحدة للمنطق المحاسبي.
