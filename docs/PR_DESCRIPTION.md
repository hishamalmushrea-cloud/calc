## ملخص

هذه الدفعة تبني على PR #2 المدمج، وتضيف تحسينات واجهة شاملة وميزات سوقية
(منقولة من تحليل تطبيق "دفتر الحسابات") مع أول Migration قاعدة بيانات آمنة.

## الميزات السوقية
- تقرير «العملاء المتأخرون» بعدد أيام التأخير (من آخر بيع/تحصيل).
- حد ائتمان لكل حساب مع تنبيه أحمر عند بلوغه.
- تصنيفات العملاء (حقل حر) تُعرض وتُعدَّل من لوحة الحساب.
- **أول Migration Room حقيقية (v1 → v2)** تضيف عمود `creditLimitMinor`
  دون مسح بيانات المستخدم (إزالة أي ترقية تدميرية).

## تحسينات واجهة المستخدم
- لوحة رئيسية بتسلسل بصري: بطاقة «صافي النقد» بارزة ثم «لك/عليك» بجناحين.
- تلوين دلالي للمبالغ في كل الشاشات (أخضر = لك، أحمر = عليك).
- بطاقات عملاء بصورة رمزية (حرف أول في دائرة ملونة).
- شاشة «المزيد» أعيد بناؤها كأقسام قابلة للطي (أكورديون).
- حالات فارغة موجّهة للمستخدم.
- تقارير ببطاقات أعمار ديون ملونة (0-30 / 31-60 / 61-90 / +90).
- «أبرز المتأخرين» يظهر مباشرة في الرئيسية.
- **إجراء سريع** من لوحة الحساب (بيع/تحصيل للعميل، شراء/سداد للمورد).
- **بحث** في شاشة العمليات (ملاحظات / رقم سند / نوع).

## ملاحظات للمراجعة
- أول دورة CI ستتحقق من الترجمة والاختبارات؛ أي خطأ سيُصلح فورًا.
- لا تغيير على تنسيق البيانات القائم؛ الـ Migration تحفظ البيانات.
